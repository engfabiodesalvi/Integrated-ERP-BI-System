# 📊 Projeto Ecossistema de Gestão Operacional Integrada

Este projeto simula o ciclo completo de operações administrativas, financeiras e logísticas de uma organização. Utilizando **Excel avançado** e **integração com Word**, a solução transforma dados brutos em um painel de Business Intelligence (BI) capaz de guiar decisões estratégicas.
 
--- 

## 🏗️ Arquitetura do Sistema

O projeto foi construído sob o princípio da **normalização de dados**, garantindo que informações de Clientes, Fornecedores e Produtos fossem relacionadas através de chaves primárias (IDs), evitando redundância.

### 1. Camada de Simulação e Geração de Dados (DB_Movimentação)

Diferente de planilhas estáticas, este projeto utiliza lógica de programação em Excel para simular 1000 transações baseadas em regras de negócio.Gerenciamento de Linha do Tempo:Utilização de MATRIZALEATÓRIA combinada com CLASSIFICAR para gerar uma cronologia realista de eventos.Fórmula: =CLASSIFICAR(MATRIZALEATÓRIA(1000;1;$B$21;HOJE();VERDADEIRO))Simulação de Fluxo com Inteligência de Estoque (Função LET):Para garantir que o sistema não simule saídas de produtos sem estoque, utilizei a função LET para armazenar o saldo_atual em variáveis antes de decidir o Tipo de Fluxo. Isso demonstra lógica de programação aplicada a planilhas.Integridade Referencial (PROCX):Busca dinâmica de nomes, preços e prazos de entrega (Lead Time) em tabelas auxiliares, simulando o comportamento de um banco de dados relacional.🛠️ Detalhamento Técnico: Fórmulas de Negócio📈 Controle de Estoque (Lógica de Inventário)O controle de inventário processa o histórico da DB_Movimentação em tempo real para fornecer o estado atual do armazém.Cálculo de Entradas/Saídas: Utilização da função SOMASES para filtrar movimentações por ID de Produto e Tipo de Operação.Lógica de Reposição:$$Status = \begin{cases} \text{Comprar Urgente}, & \text{se } Saldo < Estoque Minimo \\ \text{Estoque OK}, & \text{caso contrário} \end{cases}$$Fórmula: =SE(CONTROLE_ESTOQUE!$F2 < CONTROLE_ESTOQUE!$C2; "COMPRAR URGENTE"; "Estoque OK")💰 Gestão de Fluxo de Caixa (Financeiro)Foram desenvolvidas duas visões financeiras: Entrada de Caixa (Recebíveis de Clientes) e Saída de Caixa (Contas a Pagar a Fornecedores).Análise de Inadimplência: O sistema isola valores com status "Atrasado" para monitorar o risco financeiro.Fórmula: =SOMASES(Tabela_Movimentacao_Geral[Valor Total]; Tabela_Movimentacao_Geral[Tipo Fluxo]; "Saida"; Tabela_Movimentacao_Geral[Status Financeiro]; "Atrasado")Consolidação de Dashboard: O uso de referências estruturadas (ex: Dashboard2[@[Faturamento]:[Contas a Receber]]) garante que o resumo financeiro seja atualizado automaticamente ao expandir a tabela.📂 Integração Multissistemas (Excel + Word)Para atender aos requisitos de apoio administrativo, o projeto inclui:Relatórios Executivos: Vinculação de gráficos dinâmicos do Excel no Word via Object Linking and Embedding (OLE), garantindo que o relatório mensal se atualize com um clique.Automação de Cotações (Mala Direta): Sistema de Mala Direta vinculado à base de dados para gerar automaticamente cartas de cotação para os fornecedores que atingiram o nível crítico de reposição.🚀 Skills DemonstradasExcel: Funções Matriciais (LET, MATRIZALEATÓRIA), Funções de Busca Avançada (PROCX), Lógica Condicional Complexa e Dashboards Dinâmicos.Administrativo/Financeiro: Controle de estoque, análise de faturamento, gestão de inadimplência e logística de suprimentos.ADS: Estruturação de dados, lógica de simulação, tratamento de erros e automação de processos.🎓 Nota do DesenvolvedorEste projeto foi concebido para demonstrar como o raciocínio lógico de Análise e Desenvolvimento de Sistemas pode elevar a eficiência de tarefas administrativas tradicionais, transformando planilhas em ferramentas robustas de gestão de dados.
